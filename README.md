# Project 2

## Overview
SQL-based analysis of India's COVID-19 data using SQLite and Python,
covering cases, testing and vaccination across all states.

## Key Findings
- Maharashtra was the most affected state with 6.3 million cases
- Punjab had the highest death rate at 2.72%
- Tripura had the highest positivity rate at 5.12%
- Uttar Pradesh administered the most vaccine doses (54 million)
- India total: 513 million vaccine doses administered

## Queries Written
- Top 10 most affected states
- Death rate by state
- Monthly cases trend
- State wise positivity rate
- Vaccine coverage by state

## Tools Used
Python, SQLite, Pandas, Matplotlib

## Dataset
COVID-19 India Dataset — Cases, Testing and Vaccine data (Kaggle)
